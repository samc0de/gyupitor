**Initial Plan & How to Get Started:**
We've prepared a straightforward way for you to run the application locally using Docker. This command will build the necessary image and launch the application, ensuring all data (like your `.bq_cache` and the application's database) is handled correctly:

```shell
docker build -t bq-optimizer-app ./src/me/bq_app && docker run --rm -it -p 8000:8000 --name bq-optimizer-container -v "$(pwd)/.bq_cache:/app/.bq_cache:ro" -v "$(pwd)/db_data:/app/db_data" bq-optimizer-app
```

Once you run this command from your project's root directory (where `.bq_cache` and `src` are located), you can access the application in your web browser at `http://localhost:8000`. This initial setup provides a robust environment for us to build upon.
